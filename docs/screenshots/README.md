## How to Add Screenshots

1. Take screenshots of the running application
2. Save them in this folder with descriptive names
3. Update references in README.md and documentation
4. Optimize images for web (compress if needed)

## Tools for Screenshots

- **macOS**: Cmd+Shift+4 (area), Cmd+Shift+3 (full screen)
- **Windows**: Win+Shift+S (Snipping Tool)
- **Linux**: gnome-screenshot, Spectacle
- **Browser Extensions**: Awesome Screenshot, Fireshot

## Image Guidelines

- **Format**: PNG for UI, JPG for photos
- **Size**: Max 2MB per image
- **Resolution**: Retina-ready (2x) when possible
- **Compression**: Use tools like TinyPNG
- **Naming**: Use kebab-case (dashboard-view.png)
